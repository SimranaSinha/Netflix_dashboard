# 🎬 Netflix Movies & TV Shows Dashboard (Tableau)

An interactive Tableau dashboard that explores Netflix’s global catalog of Movies and TV Shows.  
The project analyzes content distribution by country, ratings, genres, release years, and growth trends over time, using a dark Netflix-inspired visual design.

🔗 **Live Dashboard:**  
https://public.tableau.com/app/profile/simran.abhay.sinha/viz/Netflix_17650586856280/Netflix

---

## 📌 Project Overview

This dashboard provides insights into Netflix’s content library by answering questions such as:
- Which countries contribute the most content?
- How is content distributed between Movies and TV Shows?
- What are the most common maturity ratings?
- Which genres dominate Netflix’s catalog?
- How has Netflix content grown over the years?

Users can interact with the dashboard using filters and drill into individual titles for detailed metadata.

---

## 📊 Dashboard Features

### 🔗 Netflix Logo Redirect
- Clicking on the **Netflix logo** redirects users to Netflix’s official website
- Creates a seamless connection between analytics and the streaming platform

### 🗺️ Global Content Distribution
- World map displaying total Movies & TV Shows by country
- Highlights regional contribution and global reach

### ⭐ Ratings Analysis
- Bar chart illustrating distribution across maturity ratings (TV-MA, TV-14, PG, etc.)
- Provides insight into Netflix’s audience targeting

### 🎭 Top 10 Genres
- Horizontal bar chart showing the most frequent genre combinations
- Includes documentaries, stand-up comedy, international movies, and kids’ content

### 🎥 Movies vs TV Shows Distribution
- Bubble chart showing percentage split between Movies and TV Shows
- Quick comparison of content types available on Netflix

### 📈 Content Growth Over Time
- Area chart showing total Movies and TV Shows added by year
- Highlights rapid catalog expansion after 2015

### 🧾 Interactive Metadata Panel
- Dynamic title details linked to **Type** (Movie / TV Show) and **Title** filters  
- Displays:
  - Rating  
  - Release Year  
  - Duration  
  - Date Added  
  - Genre(s)  
  - Description

## 🚀 How to Use

1. Open the **Live Dashboard** link  
2. Filter content by **Type** (Movie or TV Show)  
3. Select a **Title** to view detailed metadata  
4. Hover over charts for insights and distributions  
5. Click the **Netflix logo** to visit Netflix directly
